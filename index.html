Masuk Admin

Aplikasi absen ini dipakai di HP admin. Masukkan PIN admin 6 angka.

Di iPhone: pasang dulu aplikasi ke Layar Utama lewat tombol Bagikan di Safari, lalu buka dari ikon Absensi Kru dan masuk dari sana. Akun admin terkunci di tempat Anda pertama kali masuk.

Lupa PIN atau ganti HP? Buka spreadsheet, menu Absensi Kru > Atur/Reset PIN admin atau Reset HP admin.
